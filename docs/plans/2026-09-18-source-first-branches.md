# 簡易全体：原本起点の分岐・合流

開始HEAD 44d9150、作業ツリー清潔。単独作業。

1. 原本は既存の論理アプリ/所有コード、共有コード、独立した操作入力の定義を使う。実行構成は原本から分離する。外部サービスへ原本を作らない。
2. 操作は技術・用途・入力・出力/対象・設定・環境の一致で要約。script名/使用IDだけの違いは枝を増やさない。共通成果物の複数利用は一つの成果物から分岐し、単一段階の私有成果物は既存の追跡可能な短縮を維持。
3. 簡易専用で原本を左に整列。操作入出力だけで段階を求め、有限の到達集合で起点ごとの枝と複数起点の合流を配置。通常参照/通信を配置制約へ戻さず、元の線は保存する。
4. 右に起動/公開/適用先。環境別資源集合は元実体を保持。3Dは同じ役割・段階を使い、枝の奥行きを分ける。
5. 元ID/根拠/全体プリセットの比較、改名・任意環境・循環・部分不明・共通生成/公開のfixture、状態/ブラウザ確認、全テスト/build/lint/typecheckを実施。

セッションはメモリ内で入力置換/再読込時に再生成する実装。外部へ永続化された簡易座標はない。既存全体/プリセットをリセットせず、表示キーは維持する。

実装・検証結果と残る確認範囲は [検証記録](../technical/tab10-source-branches-review-20260918.md) を参照。
