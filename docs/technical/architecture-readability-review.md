## ID・関係・Evidenceの保存

- 正規モデルをシリアライズして表示処理前後を比較し、不変を確認。
- 実入力3件で、各相手の内訳に含む表示関係ID集合が、その対象に接する関係ID集合と一致。相手名での統合はしない。
- 全体図の描画＋内部要約＋境界に保持する元関係ID集合と、条件内の正規関係集合を照合。内部関係と真の自己関係の区別も既存テストで維持。
- 元関係は重複しない元レコードID、ソース箇所は`path/start/end`、Evidenceはさらに説明文を含む組で数える。二重の表示集約でも元レコードまでたどる。3種類の数を同じ値へ揃えていない。
- 要求元・環境・表示上の集合という補足は表示専用。元のrequest ID、owner ID、式、source ID、Evidenceを変更しない。
