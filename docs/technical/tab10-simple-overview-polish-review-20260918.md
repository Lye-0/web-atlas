## 正確性・性能・回帰

凍結した同一JSON入力を旧HEADのソースと現行ソースへ別々に与え、全体を含む既存プリセット（vehicle11、git7、web8）の投影全体のdigestを比較して一致した。モデル自身のhash、全元ノードID、全元関係IDの保存も確認。最初のlive objectとJSON roundtripの比較ではdigest差があったため、独立した旧実装も同じJSON入力で走らせる比較へ修正した。旧期待値を現行値で上書きして通す方式ではない。

独立fixtureは孤立/DBなし/道具なし、同名別対象、任意環境名、別アプリと同アプリの用途、複数出力先、内部/外側、循環、成果物分岐、一意でない生成元、成功/失敗条件、別行Evidence、大量関係を確認する。

測定はNodeでPreparedArchitectureScopeから簡易生成まで。最終測定のcoldはvehicle266ms、git383ms、web197ms、同一入力100回のキャッシュ取得は各0.05ms未満。全体/プリセット比較や正規解析の時間は含めない。描画FPSや長時間GPU負荷の計測ではない。選択・パンは要約の再生成入力にせず、初期詳細で全元関係をDOM化しない。

共有変更はSemanticFlow2D/3Dのsimple属性の表示、simple時だけの初回倍率、flowRegionsのsimple専用分岐、Architectureの文脈/関係ラベル。全体/他タブは専用分岐に入らない。共通描画、コマンドタブ全画面検索非表示/selector維持、検索・選択・状態保存等を全回帰テストで確認した。

## 限界

- vehicleの全景Fitは、残すべき独立対象が多いため文字が小さい。初回は最小倍率0.75とし、主要領域からパンで読む。全対象が常に一画面で読める保証はしない。個々の線の回り込みは対象外。
- web-atlasの新鮮な全ソース解析OOMは未解決。既存の保存入力と固定ソース回帰で補った。実環境の起動・公開・DB変更は未観測。
- 全操作を全プロジェクト/全解像度で網羅したわけではない。空入力/階層/明示展開等は既存UIテストで回帰し、今回の実ブラウザは上記代表操作を確認。
- 未特定の操作先/要求先は根拠なしに補完していない。元ID、Evidence、完全な定義位置は段階開示で保持する。
